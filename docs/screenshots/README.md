# Screenshots

Drop image files in this folder and reference them from the root `README.md`'s
Screenshots section, e.g.:

```markdown
![Donor dashboard](docs/screenshots/donor-dashboard.png)
```

A good set to cover (roughly in the order a visitor would see them):

1. **Landing page (logged out)** — shows both the donor and blood bank sections
2. **Find Blood search results** — a city search with a few results showing
3. **Donor dashboard** — logged in as `demo_donor`
4. **Blood bank dashboard** — logged in as `demo_bank`, showing the live stats
5. **My Inventory** — the bank's live stock table
6. **Pending Requests** — a bank viewing requests sorted by distance

PNG or JPG, whatever size looks good — GitHub scales them down in the README preview
either way. Keep filenames lowercase-with-hyphens (`bank-dashboard.png`) so the
reference links above stay easy to type.
